    ```html
    * Telecom company / ISP (Internet Service Provider) - a company that owns physical
    infrastructure (towers, cables, equipment) and sells you access to the internet.

    * Broadband - a wired (cable/fiber) internet connection straight into your house,
    instead of going through a mobile tower. Usually used for home WiFi.

    * Router / Modem - the box at home (often with blinking lights) that takes the
    broadband connection coming into your house and converts it into a WiFi signal
    your phone/laptop can connect to.

    * IP Address (Internet Protocol Address) - a unique
    number assigned to every device connected to the
    internet, so other devices know where to send data. 

    * DNS (Domain Name System) - a giant, distributed phonebook that converts a domain
    name (like youtube.com) into the actual IP address of the server that owns it.

    * Domain name - the human-readable website name, like amazon.com.

    * Domain Name Server - a special server whose entire job is to answer the question "what
    IP address does this domain point to?"

    * nslookup

    * window -> ipconfig

    * IPv4 (Internet Protocol version 4) - the original, older addressing
    format. Made of 4 numbers (each 0-255) separated by dots, like
    142.250.183.78. Because each number is built from 32 binary
    bits total, IPv4 can only create about 4.3 billion unique
    addresses in total.

    * IPv6 (Internet Protocol version 6) - the newer format built
    specifically to solve that shortage. It looks completely different -
    longer, and uses letters and colons instead of just dots, like: 2401:4900:1c20:abcd:0000:0000:0000:1a2b
    IPv6 can create about 340 undecilion unique
    addresses in total.
    ```
